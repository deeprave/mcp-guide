## ADDED Requirements

### Requirement: Shell scripting language guidance
The system SHALL provide shell scripting as a selectable language option covering Bash, Zsh, and common portable-shell practices.

#### Scenario: Apply shell profile
- **WHEN** a user selects shell scripting during profile selection or onboarding
- **THEN** the project SHALL receive the shell language guidance
- **AND** the guidance SHALL identify when syntax differs between Bash and Zsh
